# Muninhall — руководство пользователя

[English version](../en/user-guide.md)

Muninhall — приложение для Linux и Windows, чтобы создавать, читать и организовывать **свою
библиотеку**. Библиотека — это папка на диске с книгами и статьями (EPUB, FB2, MOBI, PDF); таких
библиотек может быть несколько, и все вместе они просматриваются как одна большая. **ЛитРес** —
подключаемая коммерческая библиотека: купленные книги и аудиокниги скачиваются и открываются во
встроенной читалке и плеере. Оформление в стиле GNOME, светлая и тёмная тема переключаются вслед
за системой. Интерфейс — на русском или английском.

## Установка

### Готовые установщики

На странице [релизов](https://github.com/arvino-t/muninhall/releases) к каждой версии приложены:

- **`Muninhall-Setup-<версия>.exe`** — установщик для Windows 10/11. Ставит программу для текущего
  пользователя, без прав администратора; Python не нужен. Ярлыки — в меню «Пуск» (и по желанию на
  рабочем столе), EPUB/FB2/MOBI/PDF — в «Открыть с помощью». Удаление — через «Параметры → Приложения».
- **`Muninhall.flatpak`** — для любого Linux с Flatpak: `flatpak install --user Muninhall.flatpak`.
  Данные общие с обычной установкой (`~/.local/share/muninhall` и т. д.). Чтение вслух во Flatpak
  пока недоступно (нет доступа к speech-dispatcher системы).

### Linux из исходников (Fedora, Ubuntu/Debian, Arch)

```
bash install.sh              # установить или обновить
bash install.sh --uninstall  # удалить
```

Приложение ставится для текущего пользователя. `sudo` спросят, только если не хватает системных
библиотек (Python 3.10+, venv, библиотеки для Qt и Chromium). Приложение живёт в
`~/.local/opt/muninhall`, команда — `muninhall`, в меню появляется «Muninhall»,
файлы EPUB, FB2 и MOBI открываются через неё.

### Windows из исходников

Дважды щёлкните `install.cmd` (или выполните
`powershell -ExecutionPolicy Bypass -File windows\install.ps1`).

Права администратора не нужны. Если Python 3.10+ не найден, установщик поставит Python 3.12
через winget. Приложение живёт в `%LOCALAPPDATA%\Programs\Muninhall`, ярлыки — в меню «Пуск»
и на рабочем столе, EPUB, FB2 и MOBI добавляются в «Открыть с помощью» (программы по умолчанию
не меняются). Удаление — через «Параметры → Приложения».

Первая установка займёт время: PySide6 (Qt со встроенным Chromium) весит около 600 МБ.

### Переход с прежней версии

До версии 0.16 приложение называлось «Читалка ЛитРес», в версии 0.16 — Shelfwise. Установщик убирает
прежнюю версию (ярлык, значок, программу), а Muninhall при первом запуске сам переносит её данные —
библиотеку, место чтения, настройки, вход в ЛитРес и папку резервных копий; старые копии тоже можно
восстановить. Перед первым запуском закройте прежнюю версию. Команда `litres-reader` продолжает работать.

## Библиотеки

Библиотеки, внесённые в программу, — в «Настройки → Библиотеки».

- **Своя библиотека** — корневая папка на диске. Её подпапки становятся подкаталогами. Файлы
  открываются на месте: приложение их не копирует, не переименовывает и не удаляет.
- **Данные своей библиотеки** (отметки «Прочитано», место чтения, состояние графа) хранятся в ней
  же, в скрытой папке `.library`. Если папка синхронизируется с облаком, данные переезжают вместе
  с книгами на другой компьютер.
- «Добавить библиотеку…» → «Своя библиотека — папка на диске…»: выберите папку и задайте имя.
  «Переименовать…» меняет имя, «Убрать» убирает библиотеку из программы (папка и её `.library`
  остаются). «Обновить список» (или F5) заново просматривает папки.
- При первом запуске из «Документов» берутся три папки, если они есть:

  | Папка | Библиотека |
  |---|---|
  | `Документы/Books/others` | Другие книги |
  | `Документы/articles` | Статьи |
  | `Документы/trainings` | Тренинги и презентации |

- У каждой библиотеки свой граф и свои резервные копии; статистика общая, но её можно смотреть
  по библиотеке.

## ЛитРес

ЛитРес подключается как библиотека: «Настройки → Библиотеки → Добавить библиотеку… → ЛитРес».
Без неё в программе нет ничего про ЛитРес. «Отключить» в строке ЛитРес скрывает её книги, вход
и синхронизацию; скачанные файлы, отметки и вход сохраняются — подключить можно снова.

**Вход.** «Войти» в строке ЛитРес (или меню → «Войти в ЛитРес») открывает сайт ЛитРес — войдите
как обычно: по паролю, коду из SMS или через соцсеть. Приложение пароль не видит и не хранит: после
входа оно пользуется сессией встроенного браузера. «Выйти» стирает сессию; скачанные книги и
прогресс остаются. Там же — «Папка для книг…»: куда скачиваются книги ЛитРес.

После входа книги из аккаунта загружаются сами; пока окно открыто, список обновляется и сам
(по умолчанию раз в 15 минут), вручную — F5.

## Библиотека на экране

Поиск по названию и автору — Ctrl+F.

**Фильтры** над списком:

- **Статус** — «Все», «Читаю», «Не читал», «Прочитано». Числа на кнопках считают книги
  выбранного источника и подкаталога.
- **Источник** — «Все» (все библиотеки вместе), «ЛитРес» (под ним «Книги» и «Аудиокниги») и каждая
  своя библиотека по имени.
- **Подкаталог** — для ЛитРес это ваши папки на ЛитРес (и «Без папки»), для своей библиотеки —
  её папки на диске. Выбор папки показывает и книги из её подпапок.
- **Сортировка** — недавние, как на ЛитРес, по названию, автору, сериям, прогрессу, дате покупки.

**Карточка книги.** Нажмите на обложку — книга скачается (EPUB, иначе FB2 или MOBI) и откроется.
Долгое нажатие или правая кнопка мыши открывает меню: читать или слушать, отметка «Прочитано»,
папки ЛитРес, скачать заново, открыть на сайте, следующая книга серии, показать файл, удалить
с устройства. На обложке — прогресс, серия и номер книги; когда книга дочитана, приложение
предлагает открыть следующую в серии.

**Папки ЛитРес:** меню книги → «Папки…». Изменения сразу уходят на ЛитРес, а без сети — при
следующей синхронизации.

**Скачать все книги:** меню → «Скачать все книги…» (или «Настройки → Общие»). Можно выбрать
только книги или книги вместе с аудиокнигами. Книги скачиваются по одной, ход виден в заголовке;
остановить — тем же пунктом меню. В конце появляется итог; книги, которые не скачались,
и причины записываются в журнал.

## Чтение

- **Листание:** касание левой или правой трети страницы, свайп, стрелки, PageUp/PageDown,
  пробел. Касание середины страницы прячет и возвращает панели — для чтения без отвлечений
  (глава и процент остаются в углах страницы).
- **Панели:** сверху «Назад», «Оглавление», «Вид текста», автолистание, чтение вслух и полный
  экран; снизу — ползунок по книге. Щелчок по ползунку сразу переносит в это место.
- **Вид текста** (кнопка «Аа»): размер шрифта, тема (авто, светлая, сепия, тёмная, чёрная),
  шрифт, межстрочный интервал, поля, ширина строки, две страницы в горизонтальном положении,
  выравнивание по ширине.
- **Жесты:** щипок двумя пальцами или Ctrl+колесо меняют размер шрифта, свайп вверх открывает
  оглавление, свайп вниз прячет или показывает панели.
- **Автолистание:** страница перелистывается сама через заданный интервал (5–120 с).
  Ручное листание начинает отсчёт заново.
- **Чтение вслух:** книга читается с текущего места, предложение подсвечивается, страницы
  и главы листаются сами. Голос системный (Linux — speech-dispatcher, Windows — SAPI).
  Для более естественного русского голоса на Linux поставьте RHVoice
  (`sudo dnf install rhvoice speech-dispatcher-rhvoice` или аналог).
- **PDF** открывается прямо в приложении; страницы показываются как есть, без перекладки текста.
- F11 — полный экран, Esc — выход из полного экрана или назад.

## Выделения и заметки

Выделите текст в книге (EPUB, FB2, MOBI или PDF) — над ним появится панель:

- **четыре цвета со смыслом**: жёлтый — «Важное», зелёный — «Совет», синий — «Понятие»,
  розовый — «Вопрос» (названия меняются в «Настройки → Интеграции → Obsidian»);
- **«Заметка»** — выделить и сразу записать мысль, вопрос или как применить;
- **«Копировать»** — текст в буфер обмена.

Щелчок по выделению открывает меню: другой цвет, заметка, копировать, удалить. Кнопка «Выделения» в
заголовке читалки — все цитаты книги по порядку (цвет, глава, заметка), щелчок переносит к месту.

Выделения своих книг хранятся в `.library/` их библиотеки и переезжают вместе с папкой; выделения
книг ЛитРес — в данных приложения. Всё попадает в резервные копии.

## Фокус

Текущий приоритет в чтении: тема, которую вы сейчас развиваете. Кнопка «◎ Фокус» под «Продолжить чтение»
(или меню → «Фокус и карта освоения») открывает страницу «Фокус»: сверху — текущие фокусы, ниже —
[карта освоения](#карта-освоения); тему из карты можно сразу сделать фокусом.

- **Фокус** — название и теги (жанры, теги ЛитРес и вики, темы, серии, авторы): книги с ними попадают в
  фокус сами. Отдельную книгу можно добавить или убрать в её меню («В фокус», «Убрать из фокуса»).
  Активных фокусов — до двух (третий отправляет самый давний в архив); прежние остаются в архиве — любой
  можно снова сделать текущим.
- **«Сейчас в фокусе»** (верх страницы): по каждому фокусу прогресс (прочитано, читаю, всего), следующая книга: сначала начатая, потом самая
  релевантная — по совпавшим тегам и близости к уже прочитанным книгам фокуса; похожие книги вне фокуса;
  кнопка «Все книги фокуса» оставляет в библиотеке только их. Книги фокуса в «Продолжить чтение» — в
  зелёной рамке. Дочитали книгу фокуса — подсказка со следующей.
- **Чтобы не застрять в одной теме**: когда прочитано «достаточно» (порог задаётся в окне фокуса,
  по умолчанию 5 книг, или 70% книг фокуса), приложение предлагает закрепить прочитанное в вики и сменить
  фокус, и показывает кандидатов — большие темы, не пересекающиеся с текущей.
- Фокус учитывают **просмотр дня** (цитаты и отрывки — сначала из книг фокуса), **граф** (книги и теги
  фокуса — в кольцах, в анализе — прогресс и смежные темы) и **Obsidian**: страница
  `wiki/plans/Фокус — <тема>.md` с тегами, прогрессом и книгами; по ней строит план локальный ассистент.

## Карта освоения

«Что я знаю» — нижняя часть страницы «Фокус». Темы библиотеки (темы вики, жанры, темы своих папок, теги вики — от
трёх книг) с уровнем освоения:

- **Не начато → Знакомство → Изучаю → Разбираюсь → Освоено.** Уровень растёт с прочитанными книгами темы и с
  тем, что осмыслено в вики (карточка книги со `status: ingested`). «Освоено» — 5 прочитанных книг и не
  меньше 40% книг темы, или 3 прочитанные и 2 осмысленные.
- По каждой теме: прочитано из скольких, читаю, время чтения, цитаты и вопросы из выделений; «Книги темы» —
  список с переходом к книге; «Сделать фокусом». Темы, которые уже в фокусе, — в зелёной рамке.
- **Куда обратить внимание**: начатые темы, где ничего не дочитано; вопросы (розовые выделения) без ответа —
  с переходом к вопросу; прочитанное, но не закреплённое ни цитатами, ни конспектом; освоенные темы — пора
  сменить фокус; большие темы, к которым не приступали.
- Темы вики, которые лишь папка хранения (например, «Книги ЛитРес»: у этих книг свои жанры), не показываются.
- Копия — страница `wiki/plans/Карта освоения.md` (таблица тем и советы; свой текст вне блока приложения
  сохраняется).

## Просмотр дня

Справа в библиотеке, под «Продолжить чтение», — две карточки на день:

- **Моя цитата** — одно из ваших выделений. Интервальное повторение: «Помню» — следующий показ через
  3, 8, 20… дней, «Позже» — завтра; сначала приходят советы и важное. «В книге» — открыть на этой цитате.
- **Из книги** — случайный законченный абзац из EPUB или PDF книги, которую вы читаете или прочитали.
  «Сохранить цитату» — добавить в выделения книги, «В книге» — открыть на этом месте.

Выбор держится весь день и меняется на следующий; история повторений — в резервных копиях.

## Аудиокниги

Аудиокниги отмечены значком наушников. Скачивается M4B или архив MP3, затем открывается плеер.

- Главы берутся из разметки внутри M4B (для MP3 — по файлу на главу): список глав с временем
  начала, переход к предыдущей и следующей; ползунок и время — внутри главы.
- Перемотка на −15 и +30 секунд, скорость от 0.75× до 2× без искажения голоса.
- Таймер сна: через заданное число минут или «В конце главы».
- Если уйти в библиотеку, звук не прерывается, а кнопка в заголовке возвращает к плееру.
- Пробел — пауза, стрелки — перемотка.

## Продолжить чтение и автопродолжение

- **Панель «Продолжить чтение»** справа в библиотеке показывает последние начатые книги —
  прочитанные и в приложении, и на телефоне или сайте ЛитРес.
- **При запуске** приложение открывает последнюю текстовую книгу на месте остановки — самую
  свежую из начатых и скачанных, с учётом чтения на ЛитРес. Аудиокниги само не включает.
  Отключается в меню или в «Настройки → Общие».
- **Место с ЛитРес:** если на ЛитРес книга прочитана или прослушана дальше, приложение само
  переходит туда; в уведомлении есть кнопка «Вернуть».
- Дочитанная книга отмечается прочитанной и на ЛитРес.

## Граф книг

Меню → «Граф книг» или Ctrl+G. Граф устроен как в Obsidian: книги и теги — узлы, связь
«книга — тег» — ребро. У каждой библиотеки свой граф: библиотека выбирается в заголовке
(по умолчанию — выбранная в фильтре «Источник»), «Все библиотеки» — общий граф. Настройки графа
(виды тегов, фильтры) запоминаются для каждой библиотеки отдельно.

- Теги: теги вики и страницы вашего хранилища Obsidian (темы, понятия, сущности, сравнения, синтез,
  проекты — со ссылками между ними), жанры и теги ЛитРес, ваши папки на ЛитРес, серии, авторы, темы
  своих книг и статей. Все виды включены; выключаются в панели слева, там же поиск и фильтр
  «Все / ЛитРес / Мои». Связи вики берутся так, как их видит Obsidian (через его CLI, если Obsidian
  запущен), иначе — из файлов вики.
- **Возможные теги** — пунктирные кружки: слова и пары слов, общие для нескольких книг, но ещё не
  ставшие тегами, и страницы, которые упоминаются в вики, но не созданы. Щелчок — подсказка, второй
  щелчок по возможному тегу — добавить его в карточки этих книг; второй щелчок по странице вики —
  открыть её в Obsidian. Переключатель «Возможные теги» в панели.
- **Анализ** (внизу панели) — по текущим фильтрам: темы и что освоено (полоска «прочитано / читаю /
  не начато»), куда обратить внимание (начато, но не дочитано; большие темы, где ничего не начато),
  мосты между областями (теги, через которые связаны разные группы книг), чего не хватает (книги без
  тегов, главные возможные теги). Щелчок по пункту показывает узел на графе.
- Наведение подсвечивает связи, щелчок по тегу выделяет его книги, по книге — открывает её.
  Колесо или щипок — масштаб, перетаскивание — сдвиг и перемещение узлов.
- Цвет книги: серый — не начата, акцентный — читаю, зелёный — прочитана.
- Жанры и теги ЛитРес подгружаются в фоне после синхронизации (один раз на книгу). Ход
  раскладки и подгрузки виден в индикаторе сверху и под заголовком окна.

## Статистика чтения

Меню → «Статистика чтения». Минуты сегодня и за неделю, дни подряд, дочитанные книги, график
за две недели и книги, на которые ушло больше всего времени. Слева в заголовке — выбор библиотеки
(по умолчанию все).

Учитывается и чтение на телефоне или сайте ЛитРес: при синхронизации прирост процента
переводится во время (текст — около 1300 знаков в минуту по объёму книги, аудио — по
длительности) и записывается на день, когда читали. На графике эта часть столбика светлее.
Скорость чтения для оценки меняется в «Настройки → Дополнительно».

## Настройки

Меню → «Настройки» или Ctrl+,. Изменения применяются сразу.

| Вкладка | Что в ней |
|---|---|
| **Общие** | язык интерфейса (как в системе, русский, English — после перезапуска); открывать последнюю книгу при запуске; только скачанные; скачать все книги (если подключён ЛитРес); статистика |
| **Библиотеки** | свои библиотеки и ЛитРес — см. [Библиотеки](#библиотеки) и [ЛитРес](#литрес) |
| **Внешний вид** | тема интерфейса (как в системе, светлая, тёмная); цвет акцента (системный или из палитры GNOME); значок приложения — девять на выбор, меняется значок окна и ярлыка в меню; горячие клавиши |
| **Чтение** | вид текста, чтение вслух, автолистание, скорость аудиокниг |
| **Интеграции** | Singularity |
| **Резервные копии** | см. [Резервные копии](#резервные-копии) |
| **Дополнительно** | как часто обновлять библиотеку с ЛитРес и «Обновить сейчас»; скорость чтения для оценки чтения на телефоне; подробный журнал; папки данных, настроек и кэша; сброс настроек |

«Сбросить настройки» возвращает вид текста, чтение, обновление и журнал к исходным; папки,
вход в ЛитРес и библиотека не меняются.

## Резервные копии

«Настройки → Резервные копии».

- **Библиотека:** вверху выбирается, к какой библиотеке относятся «Создать» и список копий.
- **Что в копии:** копия «Все библиотеки» — настройки, статистика, настройки Singularity и данные
  всех библиотек; копия одной библиотеки — её отметки, место чтения и граф. Книги, обложки и вход
  в ЛитРес в копию не входят. Токен Singularity кладётся в копию «Все библиотеки», только если
  включено «Сохранять токен Singularity».
- **Когда:** по кнопке «Создать» и автоматически — копия всех библиотек раз в день или раз
  в неделю (по умолчанию — раз в неделю). Старые копии сверх заданного числа удаляются, у каждой
  библиотеки — свой счёт.
- **Где:** по умолчанию `Документы/Backups/muninhall`; папку можно сменить. Если папка
  «Документы» синхронизируется с облаком, копии окажутся и там.
- **Восстановление:** из списка последних копий или из файла (например, с другого компьютера).
  Копия одной библиотеки восстанавливает только её. Перед восстановлением текущие данные
  сохраняются в отдельную копию, приложение перезапускается.
  Папки книг и копий остаются как на этом компьютере.
- Файлы копий доступны только вашей учётной записи.

## Singularity

«Настройки → Интеграции → Singularity → Настроить…». Вставьте API-токен из
[личного кабинета SingularityApp](https://me.singularity-app.com) («Доступ к API», с доступом
к задачам, проектам и привычкам) и выберите, что синхронизировать:

- **Задачи «Читаю»** — начатые книги становятся задачами в проекте «Книги»; дочитали — задача
  закрывается.
- **Прогресс в задаче** — процент и текущая глава в заметке задачи.
- **«Хочу прочитать»** — непрочитанные книги становятся задачами в отдельном проекте; начатая
  книга переезжает в «Книги» той же задачей.
- **Ежедневное чтение** — привычка «Чтение N минут» отмечается сама, когда за день набралось
  N минут чтения или прослушивания.
- **Проекты** — куда писать задачи: «Книги, которые читаю» и «Хочу прочитать». По умолчанию
  приложение создаёт свои проекты «Книги» и «Хочу прочитать»; в списке можно выбрать любой проект
  вашего Singularity (список появляется, когда токен вставлен). Начатые книги переезжают в новый
  проект при следующей синхронизации, дочитанные остаются на месте. Если выбранный проект удалить
  в Singularity, задачи снова пойдут в свой проект.
- **Библиотеки** — книги каких библиотек становятся задачами (по умолчанию всех; «Хочу прочитать» —
  только ЛитРес).

Синхронизация идёт после синхронизации с ЛитРес, при отметке «Прочитано» и раз в пару минут
во время чтения. Свои задачи приложение находит по `externalId`, поэтому дублей не бывает.
Названия проектов и привычек в Singularity всегда на русском — при смене языка интерфейса
дубли не появятся. Токен хранится только на этом компьютере.

## Obsidian — второй мозг

Если ваши заметки ведутся в Obsidian по схеме LLM Wiki (в хранилище есть `CLAUDE.md` и папка `wiki/`,
карточки книг — `wiki/sources/*.md` с полем `file:`), Muninhall работает с ним напрямую:

- **выделения** каждой книги сразу попадают на страницу `wiki/highlights/<Книга>.md`: цитаты по главам,
  ваши заметки, метки смысла (`#важное`, `#совет`, `#понятие`, `#вопрос`) и ссылка «в книге»;
  щелчок по ней в Obsidian открывает Muninhall на этой цитате. Приложение обновляет только свой
  блок страницы — ваши мысли выше или ниже блока остаются;
- **отметка «Прочитано»** ставит в карточке книги `status: read`, начатая книга — `reading: true`;
- **теги**: «Теги…» в меню книги — теги её карточки (вложенные через «/», с подсказками из всего
  хранилища); в графе книг они видны как «Теги вики», с родителями вложенных тегов.

Хранилище выбирается в «Настройки → Интеграции → Obsidian» (по умолчанию — «Документы»). Если
включён официальный Obsidian CLI (Obsidian 1.12+: «Настройки → Общие → Интерфейс командной строки») и
Obsidian запущен, свойства меняются через него; иначе приложение само правит Markdown-файлы.
Файлы книг не меняются никогда.

## ЛитРес и VPN (Linux)

ЛитРес не открывается через зарубежный VPN. Скрипты в `vpn-bypass/` пускают трафик к ЛитРес
напрямую через обычное подключение, а остальной трафик — через VPN. Если установлен
`vpn-killswitch`, в него добавляется исключение только для адресов ЛитРес.

```
sudo bash vpn-bypass/install.sh           # установить
sudo bash vpn-bypass/install.sh --remove  # удалить (и вернуть исходный kill switch)
```

## Где хранятся данные

| Что | Linux | Windows |
|---|---|---|
| Данные своей библиотеки (отметки, место чтения, выделения, граф) | `<папка библиотеки>/.library/` | `<папка библиотеки>\.library\` |
| Книги ЛитРес, обложки, данные ЛитРес | `~/.local/share/muninhall/` | `%LOCALAPPDATA%\muninhall\` |
| Сессия ЛитРес | `~/.local/share/muninhall/webengine/` | `%LOCALAPPDATA%\muninhall\webengine\` |
| Настройки, токен Singularity | `~/.config/muninhall/` | `%APPDATA%\muninhall\` |
| Кэш (значки сервисов) | `~/.cache/muninhall/` | `%LOCALAPPDATA%\muninhall\cache\` |

Папку для книг ЛитРес можно сменить в «Настройки → Библиотеки». Файлы данных создаются
с доступом только для владельца. Скачанные книги и прогресс остаются и после удаления приложения.

## Горячие клавиши

Сочетания ниже — по умолчанию; их можно изменить в «Настройки → Внешний вид → Горячие клавиши»
(там же — для «Статистики чтения», у неё сочетания по умолчанию нет). Клавиши читалки и плеера
не настраиваются.

| Клавиши | Действие |
|---|---|
| F5, Ctrl+R | обновить библиотеку (ЛитРес и свои папки) |
| Ctrl+F | поиск |
| Ctrl+O | открыть файл |
| Ctrl+G | граф книг |
| Ctrl+, | настройки |
| Alt+← | назад |
| F11 | полный экран |
| ←/→, PageUp/PageDown, пробел | листание в читалке |
| Esc | выход из полного экрана или назад |
| Пробел, ←/→ | пауза и перемотка в плеере |

## Ограничения

- У ЛитРес нет открытого API. Приложение использует те же адреса, что и сайт; если ЛитРес их
  поменяет, список книг или скачивание перестанут работать.
- Книги с DRM, а также доступные только для онлайн-чтения на сайте, не откроются.
- Точное место чтения на ЛитРес не записывается — только отметка «Прочитано».
- Автоматических переносов слов нет: встроенный Chromium не содержит словарей переносов.
- PDF показывается постранично как есть; изменить размер шрифта в PDF нельзя.
